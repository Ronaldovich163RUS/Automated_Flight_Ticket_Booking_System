О системе

О системе

В данном разделе вы можете ознакомиться со справочной информацией о системе. Для этого необходимо выбрать интересующий вас раздел и кликнуть по нему.

Системные требования

Операционная система: Windows, Linux, macOS.

Оперативная памыять (RAM): от 100 Мб.

Введение

Автоматизированная система бронирования авиабилетов «Fasticket» позволяет пользователям просматривать расписание рейсов, выполняемых на территории Российской Федерации, и бронировать билеты на них. Просмотр расписания с возможностью фильтрации рейсов по определенным параметрам доступен всем пользователям. Бронирование билетов может осуществляться только клиентами системы (зарегистрированными пользователями). Администратор обладает правами на редактирование данных о рейсах и самолётах. Также он может получать информацию о всех клиентах и бронированиях. Система разработана в виде веб-приложения и не требует предварительной установки.

Регистрация и авторизация

Чтобы зарегистрироваться необходимо кликнуть по иконке профиля, расположенной в верхней части главной страницы системы и находящейся справа от навигационного меню с пунктами: «Поиск билетов», «Популярные направления», «Преимущества» и «Отзывы». После этого откроется страница с формой для регистрации. Для успешного её прохождения нужно корректно заполнить такие персональные данные, как телефон, ФИО, Email, дата рождения, пароль, и после этого установить галочку в поле «Соглашаюсь с условиями передачи данных» и нажать на кнопку «Зарегистрироваться». Затем система проверит корректность данных и при наличии ошибок ввода пометит красным цветом поля ввода, в которых необходимо внести изменения. Если данные прошли проверку, то система зарегистрирует клиента в базе данных и создаст его личный кабинет.

Для авторизации необходимо на странице с формой регистрации нажать на надпись «Уже есть аккаунт? Войти». После чего откроется страница с формой авторизации. В неё нужно ввести Email или телефон и пароль. Далее произойдёт проверка корректности информации, и в случае подтверждения системой факта регистрации пользователя с такими данными произойдёт переход на страницу личного кабинета.

Главная страница приложения

На данной странице отображаются популярные направления, карта России, в пределах которой будут осуществляться перелёты, преимущества системы и отзывы клиентов. В верхней части страницы расположены логотип, иконка профиля и навигационное меню с пунктами: «Поиск билетов», «Популярные направления», «Преимущества» и «Отзывы». В нижней части страницы размещены логотип и ссылочные надписи: «О разработчиках», «FAQ» и «О системе».

Режим неавторизированного пользователя

В данном режиме пользователям доступна ограниченная функциональность. Для того чтобы воспользоваться всеми пользовательскими функциями системы, необходимо пройти процесс авторизации.

Поиск билетов

Система позволяет пользователям осуществлять поиск авиабилетов на рейсы. Для перехода к этому действию нужно, находясь на главной странице приложения, кликнуть по пункту навигационного меню «Поиск билетов». Далее, чтобы найти подходящие рейсы, необходимо выбрать пункт назначения, даты вылета и возвращения (для поиска билетов туда-обратно), количество пассажиров и их возраст, варьировав значения соответствующих фильтров. Также необходимо установить включенное состояние у одного из переключателей: «В одну сторону» или «Туда-обратно». После этого следует нажать на кнопку «Найти билеты». Для каждого рейса будут отображены следующие данные: номер, дата, время и пункт отправления, длительность полёта, дата, время и пункт прибытия, информация о ручной клади и багаже, название авиакомпании, а также цена самого билета.

Популярные направления

Пользователи могут просматривать наиболее популярные направления для рейсов. Для перехода к их просмотру необходимо, находясь на главной странице приложения, кликнуть по пункту навигационного меню «Популярные направления». После этого система отобразит самые популярные среди пользователей города для перелётов из Самары и минимальные стоимости билетов на рейсы в них.

Преимущества

В приложении представлено описание наиболее важных достоинств системы. Для перехода к просмотру преимуществ необходимо, находясь на главной странице приложения, кликнуть по пункту навигационного меню «Преимущества».

Интерактивная карта

На главной странице системы расположена интерактивная карта, отображающая все доступные пункты назначения (города, в которые осуществляются рейсы).

Отзывы

Пользователи могут изучать отзывы о приложении, оставленные клиентами системы. Для перехода к их просмотру необходимо, находясь на главной странице приложения, кликнуть по пункту навигационного меню «Отзывы».

Наиболее часто задаваемые вопросы

Система предоставляет ответы на наиболее часто задаваемые вопросы. Для перехода к их просмотру необходимо, находясь в нижней части главной страницы, кликнуть по пункту «FAQ». После этого откроется соответствующая страница. При нажатии на любой вопрос система отобразит модальное окно с текстом ответа на него. Для того чтобы его закрыть, необходимо нажать кнопку «Закрыть».

Сведения о разработчиках

В приложение имеется раздел со сведениями о разработчиках. Для перехода к его просмотру необходимо, находясь в нижней части главной страницы, кликнуть по пункту «О разработчиках». После этого откроется соответствующая страница. На ней отобразятся имена, фотографии, роли, контакты разработчиков системы и перечень выполненных ими задач.

Режим авторизированного пользователя

Авторизированные пользователи (клиенты системы) вправе использовать все функциональные возможности пользовательской части системы. Они могут воспользоваться как функциональностью для неавторизированных пользователей, так и функциями приложения, которые недоступны без прохождения процесса авторизации.

Бронирования билетов

Система предусматривает возможность бронирования билетов. Для этого, необходимо осуществить поиск билетов и затем выбрать из списка подходящий рейс(если найдено больше одного рейса, то для выбора подходящих нужно кликнуть по полю «Выбрать рейс» таким образом, чтобы в него установился символ «Галочка»). Далее нужно нажать на кнопку «Забронировать». После этого выполнится переход на страницу с бронированием билетов на рейс. Здесь необходимо внести контактные данные, выбрать количество пассажиров и совершить ввод персональных данных о каждом из них. Персональные данные самого клиента можно будет загрузить напрямую из личного кабинета,кликнув по кнопке «Заполнить из ЛК».

Далее следует выбрать подходящие места в салоне с соответствующим классом обслуживания и указать нужное количество дополнительных мест багажа. После ввода всех необходимых данных отобразится итоговая стоимость билетов. Для того чтобы завершить процесс бронирования, необходимо нажать на кнопку «Забронировать». Система проверит корректность данных и в случае успеха внесёт информацию о брони в базу данных, после чего отобразит страницу с активными бронями.

Выбор мест в салоне самолёта

Одним из пунктов бронирования билетов на рейс является выбор мест в салоне самолёта. Для того, чтобы совершить это действие, необходимо кликнуть по соответствующей кнопке на странице с бронированием билетов на рейс. Затем система откроет страницу, предназначенную для выбора мест. На ней отобразятся расстановка мест в салоне и информация о каждом из них. В легенде будут описаны цвета, которыми должны помечаться места в салоне в зависимости от класса обслуживания и состояния (свободное, занятое, выбранное, заблокированное). Их можно будет выбрать при помощи нажатия на них. После чего соответствующие места будут отмечены красным цветом.Также при этом в блоке «Выбранные места» система отобразит подробную информацию о выбранных местах, в том числе: о классе обслуживания, размере и весе ручной клади, количестве и весе багажа, возможности обмена и возврата билетов, типе питания, наличии доступных развлечений и привилегий. После нажатия кнопки «Подтвердить выбор» произойдёт сохранение выбранных мест, после чего система откроет страницу с бронированием.

Работа в личном кабинете

Авторизированные пользователи имеют возможность использовать свой собственный личный кабинет. Для того чтобы открыть его страницу, необходимо кликнуть по иконке профиля, расположенной в верхней части главной страницы системы и находящейся справа от навигационного меню с пунктами: «Поиск билетов», «Популярные направления», «Преимущества» и «Отзывы». Если авторизация не была осуществлена, то система отобразит страницу с соответствующей формой, которую нужно заполнить для перехода в личный кабинет.

Редактирование данных

В личном кабинете имеется возможность для редактирования следующих данных пользователя: ФИО, пол, дата рождения, адрес электронной почты, тип документа, серия и номер документа, номер телефона, гражданство. Для этого необходимо нажать на кнопку «Редактировать данные», произвести изменения нужной информации и затем кликнуть по кнопке «Сохранить изменения».

Доступные опции

Личный кабинет имеет опции для его удаления и выхода из него. Для удаления личного кабинета следует нажать на надпись «Удалить личный кабинет». Для выхода из него необходимо кликнуть по кнопке «Выход». Просмотр списка горячих клавиш возможен при нажатии на соответствующую кнопку.

Активные бронирования

Переход к странице активных бронирований осуществляется кликом по кнопке «Мои бронирования». На этой странице представлены все бронирования на предстоящие рейсы. Для каждой брони имеется такая информация, как время и дата отправления, время в пути, пункты отправления и прибытия, тариф багажа. Для отправки билета на email и скачивания его в формате «.pdf» следует нажать на соответствующие кнопки. Для отмены брони нужно кликнуть по кнопке «Отменить бронь»

Прошлые бронирования

Страница с историей бронирований открывается нажатием на кнопку «Прошлые бронирования». На ней отобразятся брони на рейсы, которые были уже совершены ранее. Она имеет функциональность схожую со страницей «Мои бронирования», за исключением отсутствия функции для отмены броней.

Режим администратора

Имеется возможность авторизации в системе в роли администратора. Для этого необходимо ввести на странице авторизации, зарезервированные логин и пароль. После авторизации система откроет начальную страницу администраторской части приложения.

Управление рейсами

Функциональность администраторской части предусматривает возможность управления рейсами. Чтобы осуществить переход к соответствующей странице, в навигационном меню этой части приложения следует кликнуть по раздел «Рейсы». После этого на ней отобразится подробная информация о всех рейсах, имеющая в базе данных, а именно: номер рейса, дата отправления, авиакомпания, марка самолёта, модель самолёта, время отправления, пункт отправления, пункт назначения, время полёта, количество свободных мест на рейс.

Удаление и изменение рейса

Удаление рейса из базы данных можно выполнить при помощи нажатия кнопки «Корзина», находящейся в колонке «Действия». Для изменения его данных следует кликнуть по кнопке «Карандаш», которая расположена в той же колонке, и затем установить нужные значения. Для завершения данного процесса нужно нажать на кнопку «Сохранить», а в случае выхода из него – кнопку «Отмена».

Добавление рейса

Добавление нового рейса в базу данных можно осуществить с помощью заполнения всех полей формы «Добавить новый рейс» и последующего клика по кнопке «Сохранить».

Фильтрация рейсов

Изменив параметры фильтров, можно отобразить исключительно те рейсы, которые соответствуют заданным условиям. Для этого нужно указать необходимые значения фильтров и затем нажать на кнопку «Поиск». Для возврата к демонстрации общих данных следует кликнуть по кнопке «Сбросить».

Просмотр информации о клиентах

Клиентские данные администратор не вправе редактировать: ему доступен только просмотр этой информации. Для того чтобы открыть соответствующую страницу, нужно в навигационном меню администраторской части приложения нажать на раздел «Клиенты». После чего на ней будет представлена информация о всех клиентах из базы данных, включающая в себя ФИО, тип документа, дату рождения, пол, Email, гражданство и номер телефона.

Фильтрация клиентских данных

С помощью настройки фильтров и последующего нажатия на кнопку «Поиск» можно отобразить только тех клиентов, которые подходят под выбранные критерии. Для возврата к нефильтрованным данным следует кликнуть по кнопке отмена.

Просмотр информации о бронированиях

Информация о бронированиях также, как и информация о клиентах, недоступна для редактирования в администраторской части приложения. Для перехода к данной странице необходимо в навигационном меню этой части приложения кликнуть по раздел «Бронирования». После её открытия будет отображена информация о всех бронях, имеющаяся в базе данных (идентификатор бронирования, идентификатор, клиента, номер рейса, тип багажа, общая стоимость).

Просмотр подробной информации о бронировании

Для просмотра более подробной информации о бронировании следует нажать на кнопке «Посмотреть информацию о пассажирах». После этого на экране появится модальное окно со следующей информацией: ФИО, тип документа, дата рождения, пол, email, гражданство, номер телефона, класс обслуживания, общий номер ряда, номер ряда в классе обслуживания, номер места. Для выхода из этого окна нужно кликнуть по кнопке «Закрыть».

Фильтрация данных о бронированиях

Изменяя настройки фильтров, можно выводить данные только тех бронирований, которое подходят под установленные параметры. Для этого необходимо после задания значений всем фильтрам кликнуть по кнопке «Поиск». Для выхода из режима фильтрации следует нажать кнопку «Сбросить».

Управление самолётами

Администраторская часть приложения располагает возможностями для управления данными о самолётах. Для перехода к соответствующей странице в навигационном меню данной части приложения следует кликнуть по разделу «Самолёты». На ней отобразится информация о всех самолётах, имеющаяся в базе данных (модель, производитель, авиакомпания, дальность полёта, конфигурация салона).

Удаление и редактирование самолёта

Удалить все данные о самолёте можно при помощи нажатия на кнопку «Корзина», располагающуюся в колонке «Действия». Редактирование информации о нём будет проводится при клике по кнопке «Карандаш», находящейся в том же столбце.

Фильтрация данных о самолётах

Благодаря варьированию значений определенных фильтров, имеется возможность представить данные только о самолётах, соответствующих критериям фильтрации. Для этого необходимо задать нужные значения фильтров и затем нажать на кнопку «Поиск». Для возврата к демонстрации общих данных следует кликнуть по кнопке «Сбросить».

Создание самолёта

Для создания собственного самолёта нужно открыть конструктор самолётов нажатием на соответствующую кнопку. В нём можно задать для создаваемого самолёта такие данные, как авиакомпания, марка, модель, количество проходов, дальность полёта, конфигурация (либо создать собственную конфигурацию с помощью ручной настройки). Для успешного завершения процесса создания необходимо кликнуть по кнопке «Сохранить».
