# Автоматизированная система бронирования авиабилетов «Fasticket»

Автоматизированная система бронирования авиабилетов «Fasticket» позволяет пользователям просматривать расписание рейсов, выполняемых на территории Российской Федерации, и бронировать билеты на них. 

Просмотр расписания с возможностью фильтрации рейсов по определенным параметрам доступен всем пользователям. 

**Роли и возможности:**
* **Клиенты** системы (зарегистрированные пользователи) могут осуществлять бронирование билетов на рейсы.
* **Администратор** обладает правами на редактирование данных о рейсах и самолётах. Также он может получать информацию обо всех клиентах и бронированиях.

Система разработана в виде веб-приложения и не требует предварительной установки.

## Инструкция по настройке и запуску приложения Fasticket

### 1. Установка и настройка СУБД MySQL

Установите MySQL Server, MySQL Workbench и MySQL Shell с официального сайта MySQL. В процессе установки задайте пароль для пользователя `root` и запомните его. 

После установки проверьте запуск службы MySQL. 
Для Windows: откройте службы через `Win + R`, введите `services.msc`, найдите службу "MySQL80" и запустите её. 
Альтернативно выполните в командной строке (от имени администратора):
```cmd
net start MySQL80
```

### 2. Создание базы данных

Откройте MySQL Workbench и подключитесь к локальному серверу (Local instance MySQL80), введя пароль `root`. 

Создайте новую базу данных. Вы можете выполнить следующий SQL-запрос:
```sql
CREATE DATABASE IF NOT EXISTS airline1 DEFAULT CHARACTER SET utf8mb3;
```

Затем откройте приложенный файл `database_create.sql` в MySQL Workbench, выберите созданную базу данных `airline1` и выполните скрипт для создания всех таблиц, связей, процедур и триггеров.

### 3. Настройка и запуск Spring-приложения

Получите исходный код проекта и распакуйте или склонируйте его в рабочую директорию.

Настройте файл `application.properties` (обычно находится в `src/main/resources/`). Для подключения к базе данных укажите следующие параметры:

```properties
# Настройки подключения к БД
spring.datasource.url=jdbc:mysql://127.0.0.1:3306/airline1?allowPublicKeyRetrieval=true&useSSL=false&serverTimezone=UTC
spring.datasource.username=root
spring.datasource.password=[ВАШ_ПАРОЛЬ_ОТ_MYSQL]

# Настройки почты (если требуется отправка билетов)
spring.mail.username=[ВАША_ЭЛЕКТРОННАЯ_ПОЧТА]
spring.mail.password=[ВАШ_ПАРОЛЬ_ОТ_ПОЧТЫ]
```
*Замените `[ВАШ_ПАРОЛЬ_ОТ_MYSQL]` на пароль, заданный для пользователя `root` при установке MySQL. При использовании другого пользователя базы данных укажите его имя и пароль. При отсутствии необходимости отправки email закомментируйте строки с настройками почты.*

### 4. Запуск приложения

Откройте проект в IDE (например, IntelliJ IDEA). Найдите главный класс `FasticketApplication` (аннотированный `@SpringBootApplication`) и запустите его.

Проверьте логи приложения на наличие ошибок. Убедитесь в успешном подключении к базе данных и создании таблиц. После успешного запуска система будет доступна в браузере по адресу: `http://localhost:8080`.
